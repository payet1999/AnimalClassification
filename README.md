# AnimalClassification

Android app using a custom TensorFlow Lite model to classify animals from camera pictures.

Animals DDBB : https://www.kaggle.com/datasets/alessiocorrado99/animals10?resource=download
Animals Model -> loss: 0.2883 - accuracy: 0.9055 - val_loss: 0.3348 - val_accuracy: 0.8844

Dog DDBB: https://www.kaggle.com/datasets/jessicali9530/stanford-dogs-dataset + shiba inu (30 pics)
Dog Model -> loss: 1.3236 - accuracy: 0.6195 - val_loss: 1.4665 - val_accuracy: 0.5954
